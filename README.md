# GameMode

Aplicativo Android para preparar o celular para jogar: configura orientação, brilho, volume e Não Perturbe, e restaura os ajustes anteriores ao desligar. Permite escolher o jogo e usar atalhos para ligar e desligar o modo.

Requer Android 7.0 (API 24) ou superior e autorizações do sistema para alterar ajustes e Não Perturbe.

Para gerar o APK de debug: `.\gradlew.bat :app:assembleDebug`
